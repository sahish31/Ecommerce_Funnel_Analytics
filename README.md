User Journey & Conversion Analysis Dashboard



📌 Project Overview


The User Journey & Conversion Analysis Dashboard is an interactive Power BI dashboard designed to analyze how users move through different stages of a digital platform, from their initial visit to the final purchase.
The project focuses on understanding user behavior, identifying conversion drop-offs, evaluating traffic sources, and comparing performance across devices and customer types. The dashboard transforms raw user interaction data into actionable business insights through interactive visualizations and KPIs.





🎯 Objective




The main objectives of this project are:
Analyze the complete user journey from Visit to Purchase.
Identify where users drop off during the conversion process.
Measure the overall conversion performance.
Compare conversion rates across different devices.
Analyze the effectiveness of different traffic sources.
Compare new and returning customers.
Provide interactive filtering for deeper analysis.

💡 Key Insights





Some important insights that can be derived from the dashboard include:


A significant decrease in users can be observed as they move through the conversion funnel.


Desktop users show a higher conversion rate compared to Mobile and Tablet users.


Different traffic sources generate different levels of traffic and conversion performance.


Returning and new customers show different contributions to overall conversions.


High traffic does not necessarily mean high conversion, making it important to analyze both metrics together.
