Project Overview


The User Journey & Conversion Analysis Dashboard is an interactive Power BI dashboard designed to analyze how users move through different stages of a digital platform, from their initial visit to the final purchase.
The project focuses on understanding user behavior, identifying conversion drop-offs, evaluating traffic sources, and comparing performance across devices and customer types. The dashboard transforms raw user interaction data into actionable business insights through interactive visualizations and KPIs.
